## VERIFIKATION — der wichtigste Punkt

**Nach JEDER Änderung die Browser-Konsole prüfen, BEVOR „fertig" melden.**

`node --check` sieht **nur Syntax** — das Spiel crashte zweimal trotz bestandener
Syntaxprüfung (`ReferenceError: lx`, TDZ bei `corners`). Ein Syntax-Check ist kein
Beweis, dass es läuft.

Bei „mach X"-Anweisungen **Rückfrage, ob global oder lokal gemeint** ist:
„Rampen/schräge Höhen" war nur für Wasser, nicht für Terrain.

### Test-Fallen (je 1–3x falsch gemessen)

1. Immer in der **laufenden** Instanz messen, nie per frischem `import()` —
   frische Module haben keine generierten Chunks und lesen alles als 0
   ```js
   const hot = re => performance.getEntriesByType('resource').map(r=>r.name)
       .filter(n => re.test(n)).find(n => /\?t=\d+/.test(n));
   ```
2. Chunk-Bereich im Test == generierter Chunk-Bereich. `getBlock` liest außerhalb AIR
3. Nach `setWorldSeed` immer `resetWorldState()` — sonst liefern alle Seeds gleiche Zahlen
4. Kameratests über `player.pos`/`yaw`/`pitch`, nicht `camera` — der Loop überschreibt sie
5. Exit-Codes in Datei schreiben, nicht durch Pipes leiten (`$?` kam sonst vom `grep`)
